# Equity-Research-Fidson-Healthcare-Plc-The-Impact-College-Capstone-2026
Equity research on Fidson Healthcare Plc (NGX: FIDSON): a three-statement Excel model (FY2023A–FY2029F) with base/best/worst scenarios, plus a full research report. The Impact College capstone, 2026.
This repository contains an equity research report and a linked three-statement financial model on Fidson Healthcare Plc (NGX: FIDSON), a Nigerian pharmaceutical manufacturer. It was built by Team A as a capstone project at The Impact College. The model forecasts FY2026F–FY2029F, with a scenario switch (base, best, worst) and analysis of FX losses, finance costs, working capital and cash conversion. The report covers the business, ESG, industry and macro environment, risks, catalysts and model limitations. A valuation (DCF and peer multiples) is not yet included.
